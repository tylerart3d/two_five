# Official Marine Corps histories

Retrospective publications remain in this shared collection; unit research links
to them without duplicating originals under every unit mentioned.

- [The Landing and the Buildup, 1965 — PCN 19000307600](LANDING_BUILDUP_1965.md)
- [External source manifest and checksums](IMPORT_MANIFEST.md)
- [1965 history: recovered pages 203–210 and provenance](../../corrections/landing_buildup_1965/README.md)
- [1965 history: local merged OCR reading copy](../../local/book-recovery/merged_ocr.txt)

External downloads use `scripts/import-external-research.mjs` with a Markdown
source specification. This supplements the legacy importer and records actual
URLs, edition identities, retrieval times, and SHA-256 checksums. Existing files
are verified and never overwritten with different bytes. Originals remain in
Git-ignored `_files/`. `npm run data:check` verifies both manifests. Legacy
catalog regeneration does not overwrite this collection's catalog or manifest.

Source text, OCR, and PDF scans are evidence assets. Unit research notes hold
separate extracted assertions and interpretation. No automatic public export.
